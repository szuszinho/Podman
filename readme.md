# Podman

Containerized services running with Podman on Rocky Linux.

This repository contains the configuration and deployment files for running containers on a Rocky Linux host using Podman and systemd.

## Overview

* **OS:** Rocky Linux
* **Container runtime:** Podman
* **Service management:** systemd / Quadlet
* **Configuration:** Git-managed

## Containers

Container definitions and related configuration files are organized in this repository.
